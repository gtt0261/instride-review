# InStride trajectory review

[Open the review site](https://gtt0261.github.io/instride-review/). It works in a browser with JavaScript enabled. No account or installation is required.

The airport case includes a first-person, instance-colored replay, two stop orientations, paired memory observations and an editable approach rectangle. The Floor 5 cases include two measured long routes, timed heading playback, depth diagrams and eighteen route-specific memory questions.

Use **Copy link** to share the current case. Use **Export review JSON** in the airport pilot or **Export my reviews** on Floor 5 to share judgments. Floor 5 reviewers can import and compare their exported records. Device storage and exported files hold reviews.

Original camera media can be opened locally by authorized collaborators. Public images are geometry and depth visualizations. The airport pilot uses an estimated scene scale and draft review areas.
